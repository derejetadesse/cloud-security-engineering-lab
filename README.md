# Cloud Security Engineering Lab

## Overview
This project is my hands-on cloud security engineering lab built on a Ubuntu VPS.

The goal of this lab is to gain real-world experience in:

- Cloud security engineering
- Linux hardening
- Docker security
- SIEM monitoring with Wazuh
- Incident response
- Monitoring and alerting
- DevSecOps fundamentals
- Security automation

---

## Technologies Used

- Ubuntu Server
- Docker
- Wazuh SIEM
- Linux Firewall (UFW)
- SSH Hardening
- GitHub
- Bash
- Python

---

## Project Goals

- Build practical cybersecurity skills
- Create portfolio projects for employers
- Document security configurations
- Practice incident response
- Prepare for SOC and Security Engineer roles
